# Рабочий процесс 1 — веб-чат (ручной)

> Навигация: [Установка](installation.md) · [Рабочий процесс: агент](workflow-agent.md) ·
> [Обзор синтаксиса](v2-overview.md)

Подходит, когда у вас нет ИИ-агента с доступом к терминалу: вы используете обычный веб-чат
(Claude, ChatGPT, Gemini, DeepSeek …), а конвертацию запускаете сами.

## Кратко

```
[вставить промпт в чат] → [ответить на вопросы] → [получить .txt] → [сохранить] → [lint] → [convert] → [.docx]
```

## Шаги

1. **Установите конвертер** (один раз): `pipx install sfu-converter` —
   см. [installation.md](installation.md#шаг-1-конвертер-нужен-всем).

2. **Скопируйте промпт.** Откройте [`prompts/SFU_WEB_PROMPT.md`](../prompts/SFU_WEB_PROMPT.md) и
   скопируйте **весь блок** в окно веб-чата. Это единственный файл — больше копировать ничего не
   нужно.

3. **Ответьте на вопросы ИИ.** Он спросит:
   - тип документа (лабораторная / курсовая / ВКР / НИР / практика / реферат) → выберет профиль;
   - метаданные (тема, ФИО, группа, год, руководитель);
   - **кто пишет первые разделы** (Цель, Задачи, описание / Введение):
     **Вариант A** — вы даёте текст; **Вариант B** — ИИ генерирует из темы.
   Заголовки и содержание «Ход работы» ИИ всегда придумывает сам.

4. **Получите `.txt`.** ИИ выдаст готовый исходник в одном блоке кода. Сохраните его как
   `report.txt`.

5. **Проверьте и сконвертируйте** командами, которые ИИ выведет в конце:

   ```bash
   sfu-converter lint    --input report.txt --profile <PROFILE> --syntax-version 2
   sfu-converter convert --input report.txt --output report.docx --profile <PROFILE> --syntax-version 2
   ```

6. **Если lint показал ошибки** (severity `error`) — скопируйте сообщения обратно в чат, ИИ
   исправит `.txt`, повторите. Предупреждения (`warning`) не блокируют генерацию. Флаги `--strict`
   и `--validate-output` не нужны: они помечают как ошибки ограничения самого конвертера. Частые
   коды и исправления — [v2-diagnostics.md](v2-diagnostics.md).

Готово: `report.docx` оформлен по стандарту СФУ.

## Когда лучше Flow 2 (агент)

Если у вас Claude Code / Codex / OpenCode / Gemini CLI — агент сделает шаги 4–6 сам
(напишет, прогонит lint, исправит и сконвертирует). См. [workflow-agent.md](workflow-agent.md).
