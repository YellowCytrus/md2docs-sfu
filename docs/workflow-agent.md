# Рабочий процесс 2 — ИИ-агент (автоматический)

> Навигация: [Установка](installation.md) · [Рабочий процесс: веб](workflow-web.md) ·
> [Обзор синтаксиса](v2-overview.md)

Подходит, когда у вас есть ИИ-агент с доступом к терминалу (Claude Code, Codex, OpenCode,
Gemini CLI). Агент сам пишет `.txt`, прогоняет lint, исправляет ошибки и конвертирует в `.docx`.

## Кратко

```
[установить конвертер + интеграцию] → [попросить документ] → [ответить на вопросы] → [.docx готов]
```

## Шаги

1. **Установите конвертер и интеграцию агента** — см.
   [installation.md](installation.md): шаг 1 (`pipx install sfu-converter`) + раздел вашего агента
   (плагин для Claude Code либо `AGENTS.md` / `GEMINI.md` для остальных).

2. **Сформулируйте запрос** обычным языком, например:

   ```text
   Сделай лабораторную работу №3 на тему «Реализация REST API на FastAPI».
   Студент: Иванов И. И., группа КИ22-01, руководитель Петров А. В., год 2025.
   ```

3. **Ответьте на уточнения агента.** Он:
   - подберёт профиль по типу документа;
   - покажет **структуру заголовков** будущего документа;
   - спросит про первые разделы (Цель/Задачи/Введение):
     **Вариант A** — вы даёте текст; **Вариант B** — агент генерирует;
   - попросит недостающие метаданные (никогда не выдумывает ФИО, группу, руководителя).

4. **Агент делает остальное сам:** пишет `.txt` в синтаксисе V2 → `lint --format json` →
   исправляет ошибки (severity error) в цикле → `convert --format json`.

5. **Получите отчёт:** путь к `.docx`, использованный профиль, число ошибок/предупреждений.

## Что под капотом

- **Claude Code** — набор скиллов: общий `sfu-common` (синтаксис, цикл lint/convert, диагностика)
  плюс по одному скиллу на тип документа (`sfu-report-lab`, `sfu-coursework`, `sfu-vkr`,
  `sfu-research`, `sfu-practice`, `sfu-small-works`). Нужный скилл срабатывает по формулировке.
- **Codex** — тот же набор скиллов устанавливается через `sfu-converter agents install --only codex`;
  `AGENTS.md` остаётся ручным запасным вариантом.
- **OpenCode / Gemini / Antigravity** — те же правила в одном файле [`AGENTS.md`](../AGENTS.md)
  (для Gemini — [`GEMINI.md`](../GEMINI.md)).

## Нет агента с терминалом?

Используйте Flow 1 — один промпт в веб-чат, конвертация вручную. См.
[workflow-web.md](workflow-web.md).
