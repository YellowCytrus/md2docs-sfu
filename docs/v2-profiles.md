# Профили оформления

Профиль — это набор правил оформления по стандарту СФУ: поля, шрифты, стили
заголовков, форма титульного листа, обязательные метаданные и дополнительные
проверки. Профиль указывается в `[DOC ...]` и/или флагом `--profile`.

## Как выбрать профиль

В исходнике:

```text
[DOC syntax=2 profile=lab_practical_project_reports language=ru]
```

В командной строке (переопределяет значение по умолчанию):

```bash
sfu-converter convert --input report.txt --output report.docx \
  --profile coursework --syntax-version 2
```

Список профилей с метаданными:

```bash
sfu-converter list-profiles --format json
```

## Доступные профили

| Профиль                               | Назначение                               |
|---------------------------------------|------------------------------------------|
| `common`                              | Общие базовые правила (наследуются всеми) |
| `lab_practical_project_reports`       | Лабораторные, практические, проектные     |
| `practice_reports`                    | Отчёты по практике                        |
| `research_reports`                    | Отчёты о НИР                              |
| `coursework`                          | Курсовые проекты и работы                 |
| `graduation_qualification_work`       | ВКР (выпускная квалификационная работа)   |
| `small_written_works`                 | Рефераты, контрольные, РГЗ, эссе          |
| `graphic_and_demonstration_materials` | Графические и демонстрационные материалы  |
| `project_designations`                | Обозначения проектов                      |

Каждый профиль задаёт свой набор обязательных метаданных `[META]`. Если поля не
хватает, валидатор выдаёт `TXT_MISSING_METADATA`
(см. [диагностику](v2-diagnostics.md)).

Подробные требования по каждому профилю — в папке
[`docs/formatting requirements/`](formatting%20requirements/).

## Базовое оформление

Профиль `common` задаёт базу, которую наследуют остальные:

| Параметр            | Значение                                |
|---------------------|-----------------------------------------|
| Поля страницы (A4)  | сверху 20, снизу 20, слева 30, справа 10 мм |
| Шрифт основного текста | Times New Roman, 14 pt, чёрный        |
| Выравнивание текста | по ширине                               |
| Межстрочный интервал| 1,5                                     |
| Отступ первой строки| 1,25 см                                 |

Оформление отдельных элементов:

| Элемент            | Выравнивание | Жирный | Интервал | Отступ |
|--------------------|--------------|--------|----------|--------|
| Заголовок H1       | по центру    | да     | 1,0      | 0      |
| Заголовок H2       | слева        | да     | 1,0      | 0      |
| Заголовок H3       | слева        | нет    | 1,0      | 0      |
| Основной текст     | по ширине    | нет    | 1,5      | 1,25 см|
| Подпись рисунка    | по центру    | нет    | 1,5      | 0      |
| Подпись таблицы    | слева        | нет    | 1,5      | 0      |

Назад к [обзору синтаксиса](v2-overview.md).
