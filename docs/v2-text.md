## Заголовки `[H]`

Заголовок с явным уровнем от 1 до 4.

```text
[H level=1 title="Введение"]
[H level=2 title="Обзор литературы" number=auto]
[H level=3 title="Этапы работы"]
[H level=4 title="Подготовительный этап"]
```

| Атрибут  | Обязателен | Описание                                             |
|----------|------------|------------------------------------------------------|
| `level`  | да         | Уровень заголовка: `1`–`4`                            |
| `title`  | да         | Текст заголовка                                       |
| `number` | нет        | Режим нумерации: `auto` — автонумерация по разделу    |

- Уровень вне диапазона 1–4 даёт ошибку `INVALID_HEADING_LEVEL`.
- `number=auto` включает сквозную нумерацию разделов и подпунктов.
- H4 применяется для детальной структуры. Правило качества заголовков требует
  **минимум двух** подпунктов одного уровня: одиночный подпункт не считается
  делением (`HEADING_POINT_REQUIRES_SUBPOINTS`).

## Структурные разделы `[STRUCTURAL]`

Особые разделы стандарта (реферат, содержание, введение и т. д.). Оформляются
по правилам профиля: обычно по центру, без нумерации, с новой страницы.

```text
[STRUCTURAL title="ВВЕДЕНИЕ"]
[STRUCTURAL title="СОДЕРЖАНИЕ"]
[STRUCTURAL title="СПИСОК ИСТОЧНИКОВ"]
```

Распознаваемые названия разделов:

| Название                          | Назначение                  |
|-----------------------------------|-----------------------------|
| `РЕФЕРАТ`                          | Реферат                     |
| `АННОТАЦИЯ`                        | Аннотация                   |
| `СОДЕРЖАНИЕ`                       | Оглавление                  |
| `ВВЕДЕНИЕ`                         | Введение                    |
| `ЗАКЛЮЧЕНИЕ`                       | Заключение                  |
| `СПИСОК СОКРАЩЕНИЙ`                | Список сокращений           |
| `СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ` | Список источников           |

> Заголовок `[H level=1 ...]` с таким же названием тоже распознаётся как
> структурный раздел автоматически. Но явный `[STRUCTURAL]` нагляднее.

## Абзацы `[P]`

Основной текст. Каждый абзац начинается с `[P]`.

```text
[P] Обычный абзац текста. Поддерживается выделение фрагментов.
```

Текст без маркера `[P]` вызывает предупреждение `TXT_UNKNOWN_MARKER`
(ошибку в строгом режиме).

Абзацу можно задать произвольные атрибуты, например роль для специального
оформления:

```text
[P role=example] Этот абзац помечен ролью example.
```

## Выделение текста

Внутри абзаца поддерживается Markdown-подобное выделение:

```text
[P] Поддерживается **полужирный** и *курсивный* текст.
```

| Разметка     | Результат   |
|--------------|-------------|
| `**текст**`  | полужирный  |
| `*текст*`    | курсив      |

В абзаце также допустимы встроенные сноски `[FN ...]` и `[FN_ANCHOR ...]`
(см. [ссылки и источники](v2-references.md#сноски)).

## Экранирование `[RAW]`

Если нужно вставить текст, похожий на маркер, не разбирая его — оберните в
`[RAW]` … `[RAW_END]`. Строки внутри блока выводятся как есть.

```text
[RAW]
[Эта строка не разбирается как маркер]
[RAW_END]
```

Без закрывающего `[RAW_END]` — ошибка `TXT_MISSING_BLOCK_END`.
