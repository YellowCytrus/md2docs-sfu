## Рисунки `[FIGURE]`

Однострочный маркер. Путь к изображению разрешается относительно папки `images`.

```text
[FIGURE src="diagram.png" caption="Общая схема" id=fig:overview]
```

Расширенный вариант с пояснением и нумерацией листов:

```text
[FIGURE src="overview.png" caption="Схема системы" id=fig:sys
 explanatory="1 — вход\n2 — обработчик\n3 — выход" sheet=1 total_sheets=2]
```

| Атрибут        | Обязателен | Описание                                  |
|----------------|------------|-------------------------------------------|
| `src`          | нет        | Имя файла изображения                      |
| `caption`      | нет        | Подпись к рисунку                          |
| `id`           | нет        | Идентификатор для ссылок `[REF]`           |
| `explanatory`  | нет        | Пояснения к рисунку; строки через `\n`     |
| `sheet`        | нет        | Номер листа для многолистового рисунка     |
| `total_sheets` | нет        | Общее число листов                         |

Подпись формируется автоматически («Рисунок N — …»). Рисунок без `[REF]` на него
помечается предупреждением `FIGURE_NEVER_REFERENCED`.

## Таблицы `[TABLE]`

Строки задаются через вертикальные черты `|` до `[TABLE_END]`. Первая строка —
шапка, если не указано `header=false`. Все строки должны иметь одинаковое число
ячеек.

```text
[TABLE caption="Методы HTTP" id=tbl:http]
| Метод  | Описание           |
| GET    | Получение ресурса  |
| POST   | Создание ресурса   |
[TABLE_END]
```

| Атрибут        | Описание                                                       |
|----------------|---------------------------------------------------------------|
| `caption`      | Подпись таблицы                                               |
| `id`           | Идентификатор для `[REF]`                                     |
| `number`       | Режим нумерации (`auto`)                                      |
| `header`       | `false` — первая строка не шапка                              |
| `header_rows`  | Число строк шапки (если шапка многострочная)                  |
| `unit`         | Общая единица измерения для таблицы                           |
| `column_units` | Единицы по колонкам через запятую; `-` — без единицы          |
| `continuation` | `continuation` («Продолжение») или `final` («Окончание»)       |

Примечание к таблице — отдельным маркером перед `[TABLE_END]`:

```text
[TABLE caption="Метрики" id=tbl:metrics column_units="-,шт."]
| Параметр | Значение |
| Объектов | 320      |
[TABLE_NOTE marker="*" text="Данные приведены на конец периода."]
[TABLE_END]
```

- Разное число ячеек в строках — ошибка `TXT_INVALID_TABLE_SHAPE`.
- Нет `[TABLE_END]` — ошибка `TXT_MISSING_BLOCK_END`.
- Строка-разделитель Markdown (`| --- | --- |`) не требуется и пропускается.

## Списки `[LIST]`

Пункты задаются явными маркерами до `[LIST_END]`.

```text
[LIST type=bullet]
[-] Первый пункт
[-] Второй пункт
[LIST_END]
```

Типы списков:

| `type`                      | Маркер пункта | Результат         |
|-----------------------------|---------------|-------------------|
| `bullet`                    | `[-]`         | маркированный     |
| `numbered`, `number`        | `[1)]`        | нумерованный      |
| `lettered`, `letter`        | `[а)]`        | буквенный         |

Маркер пункта — это `[-]` либо любой текст с закрывающей скобкой: `[1)]`, `[а)]`.

### Вложенные списки

Вложенный `[LIST]` привязывается к **предыдущему** пункту родительского списка:

```text
[LIST type=lettered]
[а)] Первый буквенный пункт.
[LIST type=numbered]
[1)] Вложенный нумерованный пункт.
[2)] Второй вложенный пункт.
[LIST_END]
[б)] Второй буквенный пункт.
[LIST_END]
```

- Неизвестный `type` — ошибка `TXT_MALFORMED_ATTRIBUTE`.
- Вложенный список без предшествующего пункта — ошибка.

## Формулы `[FORMULA]`

Содержимое формулы — строки между `[FORMULA ...]` и `[FORMULA_END]`. Пояснения
символов задаются маркерами `[FORMULA_SYMBOL]`.

```text
[FORMULA id=eq:energy number=auto]
E = mc^2
[FORMULA_SYMBOL name=E text="энергия, Дж"]
[FORMULA_SYMBOL name=m text="масса, кг"]
[FORMULA_SYMBOL name=c text="скорость света, м/с"]
[FORMULA_END]
[FORMULA_EXPLANATION] где E — энергия, m — масса, c — скорость света
```

| Атрибут           | Описание                                                     |
|-------------------|-------------------------------------------------------------|
| `id`              | Идентификатор для `[REF]`                                   |
| `number`          | Режим нумерации (`auto`)                                    |
| `format`          | `latex` — рендерить содержимое как формулу Word (OMML)      |
| `consecutive_with`| Связать с предыдущей формулой без лишнего интервала         |

### LaTeX и формулы Word

При `format=latex` содержимое блока — выражение LaTeX, которое конвертируется в
нативную формулу Word (OMML) через `pandoc`; формула выравнивается по левому краю
с абзацным отступом, номер `(N)` — у правого края (СТУ 7.6.1–7.6.2). Если `pandoc`
не установлен, выражение печатается как обычный текст.

```text
[FORMULA format=latex number=auto]
FV = PV \times (1 + r)^n
[FORMULA_END]
```

Строчные формулы задаются прямо в тексте через `$...$` (или `\(...\)`); они
рендерятся как встроенные формулы Word:

```text
[P] Чистый доход от аренды равен $8000 - 2500 = 5500$ руб.
```

Маркеры внутри блока:

- `[FORMULA_SYMBOL name=… text=…]` — пояснение символа; `repeats=true` помечает
  повторно используемый символ.
- `[FORMULA_END]` — конец формулы (обязателен).
- `[FORMULA_EXPLANATION] …` — необязательная строка пояснения **сразу после**
  `[FORMULA_END]`.

Последовательные формулы:

```text
[FORMULA id=eq:a number=auto]
C = a + b
[FORMULA_END]

[FORMULA id=eq:b number=auto consecutive_with=eq:a]
D = a - b
[FORMULA_END]
```
