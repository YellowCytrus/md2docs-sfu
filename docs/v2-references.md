## Перекрёстные ссылки `[REF]`

Ссылка на рисунок, таблицу, формулу, приложение или источник по его `id`.

```text
[REF target=fig:overview]
[REF target=tbl:http]
[REF target=eq:energy]
[REF target=app:a]
```

| Атрибут  | Обязателен | Описание                                  |
|----------|------------|-------------------------------------------|
| `target` | да         | Идентификатор объекта, на который ссылаемся |

- Без `target` — ошибка `TXT_MALFORMED_ATTRIBUTE`.
- Ссылка на несуществующий `id` — диагностика `REFERENCE_UNRESOLVED`.
- Повторяющийся `id` у объектов — ошибка `TXT_DUPLICATE_ID`.

Ссылка на источник из списка задаётся целью `source:N`:

```text
[REF target=source:1]
```

## Сноски

Поддерживаются две формы.

### Встроенная сноска `[FN]`

Якорь и текст сноски задаются прямо в абзаце:

```text
[P] Текст с пояснением [FN id=1 text="Это текст сноски."].
```

### Раздельная форма: `[FN_ANCHOR]` + `[FN_BODY]`

В абзаце ставится только якорь, а текст выносится в отдельный блок:

```text
[P] Текст с пояснением [FN_ANCHOR id=2].
[FN_BODY id=2]
Тело сноски может занимать несколько строк
и хранится отдельно от абзаца.
[/FN_BODY]
```

| Маркер        | Атрибуты      | Назначение                          |
|---------------|---------------|-------------------------------------|
| `[FN]`        | `id`, `text`  | Якорь + текст сноски в одном месте  |
| `[FN_ANCHOR]` | `id`          | Только якорь в тексте абзаца        |
| `[FN_BODY]`   | `id`          | Текст сноски (до `[/FN_BODY]`)      |

Диагностика: якорь без тела — `FOOTNOTE_UNMATCHED_ANCHOR`; тело без якоря —
`FOOTNOTE_UNMATCHED_BODY`; дублирующийся `id` — `FOOTNOTE_DUPLICATE`.

## Источники `[SOURCE]`

Нумерованная запись списка литературы. Простейшая форма — свободный текст:

```text
[SOURCE number=1] Петров А. В. Машинное обучение. — М.: Наука, 2023.
[SOURCE number=2] Сидорова Е. К. Анализ данных. — СПб.: Питер, 2024.
```

| Атрибут  | Обязателен | Описание                              |
|----------|------------|---------------------------------------|
| `number` | да         | Номер в списке источников             |
| `type`   | нет        | Тип структурированной записи по ГОСТ  |
| `lang`   | нет        | Язык записи, по умолчанию `ru`        |

Неверный `number` — ошибка `TXT_MALFORMED_ATTRIBUTE`.

## Структурированные записи по ГОСТ

Если указан `type`, поля записи задаются строками `ключ=значение` до `[/SOURCE]`.
Конвертер сам собирает запись по ГОСТ.

```text
[SOURCE number=1 type=book_two_authors lang=ru]
authors="Иванов И. И., Петров П. П."
title="Анализ данных" city="Красноярск" publisher="СФУ" year=2023 pages=320
[/SOURCE]
```

Типы записей (`type`):

| Значение                 | Тип источника                       |
|--------------------------|-------------------------------------|
| `normative`              | Нормативный документ / стандарт     |
| `patent`                 | Патент                              |
| `book_one_author`        | Книга, один автор                   |
| `book_two_authors`       | Книга, два автора                   |
| `book_three_authors`     | Книга, три автора                   |
| `book_four_plus_authors` | Книга, четыре и более авторов       |
| `volume`                 | Том многотомного издания            |
| `dissertation`           | Диссертация                         |
| `article`                | Статья в журнале                    |
| `electronic`             | Электронный ресурс                  |

Типичные поля: `authors`, `title`, `city`, `publisher`, `year`, `pages`,
`journal`, `number`, `url`, `accessed`. Набор полей зависит от типа; недостающее
обязательное поле даёт `BIBLIOGRAPHY_MISSING_FIELD`.

Примеры разных типов:

```text
[SOURCE number=1 type=normative lang=ru]
title="СТУ 7.5-07-2024 Работы выпускные квалификационные"
city="Красноярск" publisher="СФУ" year=2024
[/SOURCE]

[SOURCE number=2 type=article lang=ru]
authors="Петров П. П., Сидоров С. С."
title="Проверка структурированных документов"
journal="Вестник СФУ" year=2022 number=4 pages=12-18
[/SOURCE]

[SOURCE number=3 type=electronic lang=ru]
title="Документация проекта"
url=https://example.org/docs accessed=06.06.2026
[/SOURCE]
```
