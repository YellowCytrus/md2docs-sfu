титульный лист, обозначение проекта, список сокращений, приложения, секции с
другим форматом листа, а также графические и демонстрационные материалы.

## Титульный лист `[TITLE_PAGE]`

Вставляет автоматический титульный лист по профилю. Данные берутся из `[META]`.

```text
[TITLE_PAGE]
```

Необязательный атрибут `profile` переопределяет форму титульного листа.

## Обозначение проекта `[DESIGNATION]`

Код проекта по стандарту (например, `ДП-23.05.02-2026 ABCDEF.001 Э1 ПЗ`).

```text
[DESIGNATION prefix=ДП specialty=23.05.02 group=ABCDEF.001 document=ПЗ year=2026 schema=Э1]
```

| Атрибут     | Обязателен | Описание                                |
|-------------|------------|-----------------------------------------|
| `prefix`    | да         | Префикс документа (`ДП`, `КР`, …)        |
| `specialty` | да         | Код специальности                       |
| `document`  | да         | Код документа (`ПЗ`, …)                  |
| `group`     | нет        | Код группы / классификатор              |
| `year`      | нет        | Год                                     |
| `schema`    | нет        | Код+тип схемы (`Э1`); можно разбить на `schema_code` и `schema_type` |

Отсутствие обязательного атрибута — ошибка `TXT_MALFORMED_ATTRIBUTE`.

## Список сокращений `[ABBREVIATIONS]`

Пары «сокращение — расшифровка» до `[ABBREVIATIONS_END]`. Можно задавать
маркерами `[ABBR]` или строками-таблицей с `|`.

```text
[ABBREVIATIONS]
[ABBR short=AST long="абстрактное синтаксическое дерево"]
[ABBR short=CLI long="командный интерфейс"]
| TXT | текстовый исходный файл с разметкой |
[ABBREVIATIONS_END]
```

| Атрибут `[ABBR]` | Описание         |
|------------------|------------------|
| `short`          | Сокращение       |
| `long`           | Полная расшифровка |

## Разрыв страницы `[PAGE_BREAK]`

Принудительный переход на новую страницу.

```text
[PAGE_BREAK]
```

## Приложения `[APPENDIX]`

Начинает раздел приложения. Буква может назначаться автоматически.

```text
[APPENDIX id=app:a letter="А" title="ПРИЛОЖЕНИЕ А" type="справочное"
 subtitle="Матрица покрытия" sheet=A4 independent=false]
```

| Атрибут       | Описание                                            |
|---------------|-----------------------------------------------------|
| `id`          | Идентификатор для `[REF]`                            |
| `letter`      | Буква приложения (А, Б, В…); иначе назначается авто  |
| `title`       | Заголовок приложения                                |
| `type`        | Тип: `справочное`, `обязательное` и т. п.            |
| `subtitle`    | Подзаголовок                                        |
| `sheet`       | Формат листа (см. [справочник](#справочник-значений))|
| `independent` | `true` — самостоятельный документ                   |

Приложения должны идти после списка источников
(`STRUCTURE_APPENDIX_BEFORE_SOURCES`).

## Секции `[SECTION]`

Вложенный фрагмент с собственной ориентацией, форматом листа, рамкой и формой
основной надписи. Содержимое разбирается тем же парсером v2.

```text
[SECTION orientation=landscape sheet=A3 frame=text_following form=form_3]
[P] Этот абзац — внутри альбомной секции A3 с рамкой и основной надписью.
[TABLE caption="Вложенная таблица"]
| Объект | Назначение |
| Node   | Узел AST   |
[TABLE_END]
[/SECTION]
```

| Атрибут       | Описание                                              |
|---------------|------------------------------------------------------|
| `orientation` | `portrait` или `landscape`                           |
| `sheet`       | Формат листа                                         |
| `frame`       | Тип рамки                                            |
| `form`        | Форма основной надписи (`form_1`…`form_6`)            |

Закрывается `[/SECTION]`.

## Графические материалы `[DRAWING]`

Лист чертежа/схемы с рамкой и основной надписью (форма 5/6). Параметры тела
задаются строками `ключ=значение` до `[/DRAWING]`.

```text
[DRAWING sheet=A1 frame=graphic form=form_5 scale="1:50"]
src="overview.png"
designation=ДП-23.05.02 ABCDEF.001 Э3
font=type_A
[/DRAWING]
```

| Атрибут       | Описание                                  |
|---------------|-------------------------------------------|
| `sheet`       | Формат листа (A1, A2, …)                   |
| `frame`       | Тип рамки (обычно `graphic`)              |
| `form`        | Форма основной надписи                     |
| `scale`       | Масштаб, например `1:50`                   |
| `src`         | Файл изображения                          |
| `designation` | Обозначение для основной надписи          |
| `font`        | Тип чертёжного шрифта (`type_A`, `type_B`) |

## Плакаты `[POSTER]`

Плакатный лист (обычно A1) с основной надписью на обороте. Вложенное содержимое
разбирается парсером v2.

```text
[POSTER format=A1 title="Плакат архитектуры" fill=75]
[P] Содержимое плаката.
[/POSTER]
```

| Атрибут               | Описание                                       |
|-----------------------|------------------------------------------------|
| `format`              | Формат листа                                   |
| `title`               | Заголовок плаката                              |
| `fill`                | Плотность заполнения, %                         |
| `reverse_title_block` | `false` — без основной надписи на обороте       |

## Слайды `[SLIDE_DECK]`

Набор слайдов формата A4 (можно вывести в PPTX). Каждый слайд — `[SLIDE]` …
`[/SLIDE]`. Поля слайда задаются атрибутами или строками `ключ=значение`, текст
тела — обычными строками.

```text
[SLIDE_DECK format=A4]
[SLIDE first_slide=true title="Заголовок" student="Иванов И. И." supervisor="Петров П. П." fill=80]
university="Сибирский федеральный университет"
city="Красноярск"
year=2026
Ключевые тезисы первого слайда.
[/SLIDE]
[SLIDE title="Второй слайд" fill=82]
Текст второго слайда.
[/SLIDE]
[/SLIDE_DECK]
```

| Атрибут `[SLIDE]` | Описание                                      |
|-------------------|-----------------------------------------------|
| `first_slide`     | `true` — титульный слайд (нужны поля автора)   |
| `title`           | Заголовок слайда                              |
| `fill`            | Плотность заполнения, %                        |

У первого слайда обязательны поля автора/руководителя
(`SLIDE_REQUIRED_FIRST_FIELDS`).

## Справочник значений

**Формат листа (`sheet` / `format`):** `A4`, `A3`, `A3x4`, `A4x4`, `A2`, `A1`.

**Ориентация (`orientation`):** `portrait`, `landscape`.

**Тип рамки (`frame`):** `none`, `text_first`, `text_following`, `graphic`.

**Форма основной надписи (`form`):** `form_1`, `form_2`, `form_3`, `form_4`,
`form_5`, `form_6`.
