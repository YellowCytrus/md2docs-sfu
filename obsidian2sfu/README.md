# obsidian2sfu

Конвертер заметок Obsidian (Markdown) в документы Word по оформлению СФУ.

```
заметка.md (+ вложения)  →  заметка.txt (синтаксис V2)  →  заметка.docx
```

Результат: титульный лист из `title_reference.docx` с подстановкой ваших данных,
настоящее поле Word «Содержание» с отточием, нумерация таблиц и рисунков по
разделам (1.1, 2.3, А.1 …), списки/таблицы как Word-сущности, Times New Roman 14 pt.
Жирное начертание `**вот так**` внутри ячеек таблиц сохраняется в Word, а ширины
колонок подстраиваются под объём текста в них.

## 1. Установка

### Linux

Из архива `sfu-toolkit`:

```bash
tar xzf sfu-toolkit.tar.gz
cd sfu-toolkit
./install.sh
```

Либо вручную (если репозиторий уже склонирован и venv создан):

```bash
python3 -m venv .venv
.venv/bin/pip install -e .
```

### Windows

1. Установите **Python 3.10+** (python.org, галочка «Add python.exe to PATH») и **Git**.
2. Склонируйте/распакуйте проект, откройте **PowerShell** в его корне и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\pip install -e .
```

Либо, если есть PowerShell-установщик из архива:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

## 2. Запуск

### Linux

```bash
# если ставили через install.sh — команда уже в PATH:
obsidian2sfu "Универ/Сети/Отчёт.md"

# либо напрямую:
~/Programs/tupoi_word/obsidian2sfu/obsidian2sfu "Универ/Сети/Отчёт.md"
```

### Windows

```bat
:: если ставили через install.ps1 — команда obsidian2sfu доступна из cmd/PowerShell
obsidian2sfu "Универ\Сети\Отчёт.md"

:: либо из корня проекта:
obsidian2sfu\obsidian2sfu.cmd "Универ\Сети\Отчёт.md"

:: либо напрямую интерпретатором:
.venv\Scripts\python.exe obsidian2sfu\obsidian2sfu.py "Универ\Сети\Отчёт.md"
```

Путь к заметке можно давать относительно хранилища (`--vault`, по умолчанию
`~/obsidian_backup`) или абсолютным. Рядом появятся `Отчёт.docx`, `Отчёт.txt`,
папка `images/` и PDF-превью (если установлен LibreOffice).

### Полезные флаги

| Флаг | Что делает |
|------|------------|
| `--out ПУТЬ.docx` | куда сохранить (по умолчанию рядом с заметкой) |
| `--vault ПУТЬ` | корень хранилища Obsidian |
| `--config ФАЙЛ.json` | дополнительный конфиг |
| `--set КЛЮЧ=ЗНАЧЕНИЕ` | разово переопределить поле (можно несколько) |
| `--sources-file ФАЙЛ` | список источников, по одному в строке |
| `--title-template ПУТЬ.docx` | другой шаблон титульного листа |
| `--no-pdf` | не собирать PDF |

## 3. Конфиги (JSON)

Метаданные титульника берутся по приоритету:

1. значения по умолчанию;
2. **общий конфиг** — `~/.config/sfu/obsidian2sfu.json` (Linux) или
   `%APPDATA%\sfu\obsidian2sfu.json` (Windows);
3. **конфиг заметки** — `<заметка>.sfu.json` рядом с `.md`;
4. **`--config ФАЙЛ.json`**;
5. **`--set КЛЮЧ=ЗНАЧЕНИЕ`**.

Также читается YAML-frontmatter заметки (`key: value`).

### Поля титульника

Внутри `meta`:

| Поле | На титульнике |
|------|----------------|
| `document_type` | вид работы, напр. `ОТЧЕТ О ПРАКТИЧЕСКОЙ РАБОТЕ №2` |
| `title` | тема (в кавычках) |
| `student` | ФИО студента |
| `group` | группа |
| `record_book` | номер зачётки |
| `teacher` | преподаватель |
| `institute` | институт |
| `department` | кафедра |
| `city`, `year` | город, год |

### Пример `<заметка>.sfu.json`

```json
{
  "meta": {
    "title": "Задание 2",
    "group": "КИ23-14Б",
    "record_book": "032319377",
    "teacher": "Д. В. Зябликов"
  },
  "sources": ["Первый источник", "Второй источник"]
}
```

Файл кладётся рядом с заметкой и подхватывается автоматически. Готовые наборы:
`Trotsenko.json`, `economics.json` (запуск с `--config`).

### Прочие ключи конфига

| Ключ | Назначение |
|------|------------|
| `profile` | профиль оформления (по умолчанию `lab_practical_project_reports`) |
| `sources` | список источников → «СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ» перед приложениями |
| `kv_first_cells` | таблицы-«карточки» без шапки |
| `ref_fixes` | замены в тексте (напр. перекрёстные ссылки) |

Пример с источниками:

```json
{
  "meta": { "title": "Определение кратчайшего расстояния. В-7" },
  "sources": ["Библиотечно-издательский комплекс СФУ : [сайт]. — URL: …"]
}
```

## 4. Требования

- Python 3.10+
- `sfu_converter` (устанавливается из репозитория, `pip install -e .`)
- LibreOffice и `pdftotext` (poppler) — для PDF-превью и номеров страниц в
  содержании (без них DOCX тоже собирается, только содержание будет без номеров)
